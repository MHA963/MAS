## CORE DEFINITIONS

### What is an agent?
An agent is a computer system situated in some (real or virtual) environment, capable of autonomous action to achieve delegated or self-imposed objectives.

**Key points:**
- Operates as a persistent perception–decision–action loop: perceive environment, update internal state (optional), select action, execute, repeat
- Can be purely software (e.g., chatbot) or embodied (robot)
- Continuously interacts with environment rather than computing single output and stopping

### What is a multi-agent system (MAS)?
A MAS is a system composed of multiple interacting agents, where:
- Each agent has its own goals, capabilities and local view
- No single agent necessarily has the full picture
- Global behavior emerges from their interactions
- No single central controller; coordination emerges via communication and interaction rules

---

## KEY AGENT PROPERTIES

### 1. Autonomy
- **Definition:** Acts without direct human or other-system control, choosing its own actions
- **Components:**
  - Self-sufficiency: can act using its own resources
  - Self-directedness: sets/sub-selects goals
  - Task-dependent: degrees of dependence on others
- **Flexibility:** Concept is flexible—level of autonomy depends on task, time horizon, and who evaluates it
- **With social behavior:** Autonomy does NOT mean isolation; agents may choose to ask for help or help others, based on willingness-to-interact models (dependence theory)

### 2. Social behavior
- Interacts with other agents (communication, cooperation, competition)
- Willingness to interact: who to help and who to ask for help?
- Integral to agent research

### 3. Reactive
- Responds to changes in the environment in a timely way
- Works well in simple/fast-changing tasks
- Alone, not sufficient for complex goals

### 4. Proactive
- Takes initiative, goal-directed behavior instead of only reacting
- Needed when partial observability + long-horizon goals require internal state/model and planning

## ENVIRONMENT DIMENSIONS & DESIGN CONSEQUENCES

| Dimension | Types | Design Implication |
|-----------|-------|-------------------|
| **Deterministic vs Stochastic** | Same action → same result vs probabilistic outcomes | Deterministic supports deliberative planning; stochastic pushes toward probabilistic reasoning, learning, robust reactive layers |
| **Accessible vs Partially Observable** | Full vs limited knowledge of true state | Full observability supports simple planning; partial observability requires belief tracking, sensing strategies |
| **Static vs Dynamic** | Changes only when agent acts vs changes while agent thinks | Dynamic world → need replanning/reactive control because decisions become stale; static allows offline planning |
| **Discrete vs Continuous** | Discrete steps vs continuous | Affects representation and computational methods |

## UTILITY FUNCTIONS

### Definition
A utility function maps states or runs to a numeric value representing how "good" they are for the agent.

### Key points:
- Formal performance measure the agent optimizes
- Can be defined over:
  - Single run (reward-to-go)
  - Distributions of runs (expected performance)
  - States within a run
  - Entire runs
- Provides success criteria in given environments
- Bridge to later topics: MDPs/RL optimize expected return/value under uncertainty

## DISTINGUISHING AGENTS FROM RELATED CONCEPTS

### Agents vs Objects (OOP)
- **Objects:** Passive, invoked via method calls, no autonomous goal pursuit, no common goal assumption
- **Agents:** Autonomous, goal-driven, decide when/how to act based on perceptions

### Agents vs Expert Systems (classic AI)
- **Expert systems:** Static rule bases, limited/no continuous sensing/acting loop, no continuous environmental interaction
- **Agents:** Continuously interact with environment, act in real time, broader objectives

### Agents vs Distributed Systems
- **Distributed systems:** Focus on reliability, concurrency, often fixed coordination protocols, hardwired coordination
- **MAS:** Autonomous decision-making, self-interest (not necessarily common goal), no hardwired coordination—emerges via interaction/communication protocols

### Agents vs "AI"
- **AI:** Toolkit of components (learning, planning, vision, reasoning, etc.)
- **Agents:** Integrated entity that uses these components to continuously sense, decide, act, and interact socially
- **Key difference:** AI = components; Agent = integration + sociality

### Agents vs Game Theory
- GT: descriptive, rationality assumption
- Agents: can model bounded rationality, learning, adaptation

### Agents vs Social Science
- Agents as useful tool for studying human societies
- Computational models of social phenomena

## MAS CHARACTERISTICS & MOTIVATION

### Typical MAS characteristics
- Multiple agents with local information and goals (handles spatial distribution and partial observability)
- No single central controller
- Coordination emerges via communication and interaction rules
- Self-organization: system-level patterns emerge (e.g., flocking, foraging)

### Why use MAS instead of single powerful agent?
- **Scalability:** Better handling of large-scale problems
- **Robustness:** Failure tolerance—system continues if one agent fails
- **Spatial distribution:** Agents in different physical locations (e.g., robots, sensors)
- **Partial observability:** Local views aggregate to global understanding
- **Emergent behaviors:** Hard to design centrally

### Motivation examples
- Vehicle platooning (moving together with small inter-vehicle distances)
- Sensor networks and surveillance (distributed tracking with cameras)
- Robotics teams (multi-robot missions)
- Distributed problem-solving

## COMMUNICATION STYLES IN MAS

### 1. Direct (point-to-point)
- Sending messages to specific agents
- **Advantage:** Targeted, efficient for known recipients

### 2. Global (broadcast)
- Broadcasting to all agents
- **Advantage:** Fast global awareness, simple coordination

### 3. Environmental (stigmergy)
- Leaving information in the environment (e.g., pheromone trails)
- **Advantage:** Robust, low direct communication requirements, scalable, works without direct agent-to-agent links

## ETHICS IN AI/MAS

### Key issues:
1. **Bias:** E.g., used by employers in hiring systems
2. **Criticality (safety):** E.g., autonomous drones in warfare
3. **Data privacy:** Think twice before sharing secrets with chatGPT
4. **Transparency:** How are agents making decisions? What values are encoded?
5. **Regulation:** E.g., AI Act—in theory and practice

### Single agent vs group of agents (MAS)
- **MAS-specific challenges:**
  - Emergent outcomes harder to predict/control
  - Diffusion of responsibility (who is accountable?)
  - Harder transparency/debugging
  - Interactions can amplify bias or unsafe behavior
- **Example:** Surveillance sensor network privacy concerns

## COMPLETE EXAM QUESTIONS & ANSWERS

### Q1: How is an agent defined and what are its main characteristics?
**Answer:**
An agent is a computer system situated in an environment that can act autonomously to achieve given objectives, either delegated or self-imposed. It operates as a persistent perception–decision–action loop: perceive, decide, act, repeat. Its main characteristics are: (1) autonomy—acts without direct external control; (2) social behavior—interacts with other agents; (3) reactive—responds to environmental changes in a timely way; and (4) proactive—takes initiative and shows goal-directed behavior instead of just stimulus-response.

---

### Q2: What is the difference between an agent and a simple program or object?
**Answer:**
A simple program or OOP object executes functions only when explicitly called and does not pursue its own goals; it is passive and invoked via method calls. An agent, by contrast, decides on its own when and how to act based on perceptions and objectives, showing autonomy and persistent goal-driven behavior. The agent continuously interacts with its environment in a sense-decide-act loop, while an object waits for external invocation.

---

### Q3: What is a multi-agent system and why use MAS instead of a single powerful agent?
**Answer:**
A multi-agent system consists of multiple interacting agents, each with local views and goals, whose collective behavior solves a larger task. MAS are beneficial for: (1) scalability—handling large problems; (2) robustness—failure tolerance; (3) spatial distribution—agents in different physical locations; (4) partial observability—local views aggregate to global understanding; and (5) emergent behaviors that are hard to design centrally. MAS handle distributed scenarios better than a single monolithic agent.

---

### Q4: How does the environment type influence agent design?
**Answer:**
In deterministic, fully accessible, static environments, simple planning and reasoning may be sufficient, since outcomes are predictable and the world does not change while planning. In stochastic, partially observable, dynamic environments, agents need more robust strategies—reactivity, learning, probabilistic reasoning—to cope with uncertainty. Dynamic worlds especially require replanning or reactive control because decisions become stale; partial observability demands belief tracking and sensing strategies.

---

### Q5: What is a utility function and why is it important?
**Answer:**
A utility function assigns numerical scores to states or entire runs, quantifying how desirable they are for the agent. It is the formal performance measure the agent optimizes. Utility functions allow agents to compare options, define success criteria in given environments, and provide the basis for value functions and optimal policies in MDPs and RL. They can be defined over states within a run or over distributions of runs for expected performance.

---

### Q6: In what ways are agents related to AI, and how do they differ?
**Answer:**
AI provides components like perception, planning, learning, and reasoning that can be used inside an agent. An agent is the integrated entity that uses these AI components to continuously sense, decide, and act in an environment while interacting socially with other agents. The key difference: AI is the toolkit of components; an agent is the complete system that integrates these components into a coherent, autonomous, socially-situated entity.

---

### Q7: What ethical issues arise when deploying autonomous agents and MAS?
**Answer:**
Ethical issues include: (1) biases in decision rules or training data (e.g., unfair hiring systems); (2) safety and criticality in high-stakes applications (e.g., autonomous weapons); (3) privacy risks when collecting and sharing data; (4) transparency—understanding how agents make decisions and what values are encoded; and (5) regulation needs (such as the AI Act). In MAS specifically, emergent group behavior can be opaque, responsibility is diffused across agents, and interactions can amplify bias or unsafe behavior, making debugging and accountability harder.

---

### Q8: Give a concrete agent example and identify: environment, perceptions, actions, objective.
**Answer:**
Example: **Autonomous vacuum robot**
- **Environment:** Rooms in a house (real, physical)
- **Perceptions:** Infrared/bump sensors detect obstacles and walls; dirt sensors detect debris
- **Actions:** Move forward/backward, turn, activate suction
- **Objective:** Clean all accessible floor area while avoiding obstacles and returning to charging station when battery is low
This illustrates the situated control loop: sense dirt/obstacles → decide direction/action → execute movement/cleaning → repeat.

---

### Q9: Why is an agent *not* just AI?
**Answer:**
AI is a collection of components—learning algorithms, planning methods, computer vision, reasoning systems—that provide capabilities. An agent is more: it is an integrated, autonomous entity that continuously inhabits an environment, using AI components within a perception–decision–action loop. Critically, sociality (interaction with other agents) is integral to agent research but not necessarily central to AI components. AI = toolkit; agent = integrated system with autonomy and social behavior.

---

### Q10: Explain autonomy levels with an example (e.g., self-driving car).
**Answer:**
Autonomy is a flexible concept with varying levels depending on task, time, and assessor. For self-driving cars: Level 0 has no automation; Level 1 has driver assistance (cruise control); Level 2 has partial automation (lane keeping + adaptive cruise); Level 3 has conditional automation (car drives, human must be ready); Level 4 is high automation (car drives in most conditions without human); Level 5 is full automation (no human needed). Higher autonomy means more self-directed goal handling with less external intervention, but autonomy is task- and context-dependent.

---

### Q11: What does it mean that MAS has "no hardwired coordination"?
**Answer:**
In MAS, coordination is not fully fixed by a central script or predetermined protocol. Instead, agents decide locally how to act and interact, and system-level coordination emerges from these decentralized interactions and communication. There is no single controller dictating every agent's action; rather, agents follow interaction rules, negotiate, or communicate, and coordinated behavior arises dynamically. This contrasts with distributed systems where coordination is often hardwired into fixed protocols.

---

### Q12: Give three communication styles in MAS and one advantage of each.
**Answer:**
(1) **Direct (point-to-point):** Sending messages to specific agents—advantage is targeted, efficient communication when recipients are known. 
(2) **Global (broadcast):** Broadcasting to all agents—advantage is fast global awareness and simple coordination without tracking who needs what. 
(3) **Environmental (stigmergy):** Leaving information in the environment (like pheromone trails)—advantage is robustness, low direct communication requirements, scalability, and works without direct agent-to-agent links (e.g., ant foraging).

---

### Q13: In what environment types is purely reactive behavior enough, and when do you need more?
**Answer:**
Purely reactive behavior (stimulus-response) is enough in simple, fast-changing environments where immediate response is critical and tasks are short-horizon (e.g., obstacle avoidance). When facing partial observability, long-horizon goals, or complex multi-step plans, agents need more: internal state/memory to track beliefs, model-based reasoning to predict outcomes, and proactive planning to achieve distant objectives. Dynamic environments especially benefit from combining reactive (fast response) and deliberative (planning) layers.

---

### Q14: What makes ethics harder in MAS than in a single agent?
**Answer:**
In MAS, ethics is harder because: (1) emergent outcomes arise from interactions, making behavior harder to predict or control; (2) responsibility is diffused—no single agent is clearly accountable; (3) transparency and debugging are more difficult when behavior emerges from many local decisions; and (4) interactions can amplify bias or unsafe behavior (e.g., herding effects, cascading failures). Example: in a surveillance sensor network, privacy violations can emerge from data fusion across agents even if no single agent violates privacy alone.

---

### Q15: What does "situated" mean in the agent definition?
**Answer:**
"Situated" means the agent exists within and directly interacts with an environment—real or virtual. The agent receives perceptions from that environment and can perform actions that affect it. This is key to distinguishing agents from pure computation: agents are embedded in a context where their actions have consequences, and they must respond to ongoing environmental changes, forming a continuous sense-act loop rather than a one-shot input-output computation.

---

### Q16: Explain the concept of "willingness to interact" in autonomous agents.
**Answer:**
Willingness to interact refers to an agent's choice of who to help and who to ask for help, based on its own goals, resources, and dependencies. Autonomy does not mean isolation—autonomous agents can strategically decide to collaborate or request assistance when beneficial. This connects to dependence theory: an agent may depend on others for certain capabilities or information, and social behavior involves modeling these dependencies and deciding when cooperation is worthwhile.

---

### Q17: How do you model self-organization in MAS?
**Answer:**
Self-organization in MAS means system-level patterns emerge from local agent interactions without central control. You model it by: (1) defining simple local rules for each agent (e.g., attraction/repulsion in flocking); (2) specifying interaction mechanisms (direct communication, environmental cues/stigmergy); and (3) allowing collective behavior to arise dynamically (e.g., swarm patterns, foraging trails). Emergent properties like coordination, load balancing, or pattern formation appear at the system level even though no agent explicitly plans the global outcome.

---

### Q18: Why is MAS useful for spatial distribution problems?
**Answer:**
MAS excel at spatially distributed problems because: (1) each agent can be physically located where sensing/action is needed (e.g., robots in different rooms, sensors in different locations); (2) local perception and action are often more efficient than relaying everything to a central processor; (3) communication bandwidth and latency favor local decision-making; and (4) robustness increases since the system does not rely on a single point (central controller) that could fail or become a bottleneck.

---

### Q19: What is the difference between reactive and proactive behavior? When do you need both?
**Answer:**
**Reactive behavior:** Responds directly to environmental stimuli without planning (stimulus-response). Fast, works well for immediate threats or fast-changing conditions (e.g., obstacle avoidance).
**Proactive behavior:** Goal-directed, involves planning and taking initiative to achieve objectives even without immediate external triggers.
You need both when operating in complex, dynamic environments: reactive layers handle urgent, fast changes (reflex responses), while proactive layers pursue long-term goals through planning. This is the hybrid reactive/deliberative architecture approach.

---

### Q20: How does the AI Act relate to MAS and agent ethics?
**Answer:**
The AI Act is EU regulation aimed at governing AI systems based on risk levels (unacceptable, high, limited, minimal risk). For MAS, this means: (1) high-risk MAS (e.g., autonomous vehicle fleets, critical infrastructure) face strict transparency, accountability, and safety requirements; (2) developers must ensure agents make decisions that are explainable and auditable; (3) bias and fairness must be addressed across the system, not just individual agents; and (4) accountability mechanisms must handle emergent behavior and distributed responsibility. The Act pushes MAS designers to embed ethics by design, not as an afterthought.
